# Weisone License Scope — Glyphin Research Repository

This repository contains the Glyphin research program and experimental implementations associated with Weisone Systems.

The canonical production-license terms for Weisone technology are maintained in the Weisone Kernel repository's `License.md` and `WEISONE_TECHNOLOGY_SCOPE.md`.

## Technology relationship

The current Weisone technology family includes:

- **Glyphin** — symbolic memory architecture and related implementation mechanisms;
- **Dual Cone Variator** — planned adaptive context and resource-allocation mechanism;
- **Weisone Kernel** — orchestration and integration layer maintained in the separate `weisone-kernel` repository; and
- related memory interfaces, adapters, resource-conservation mechanisms, and runtime integration components explicitly designated as Weisone technology.

## Research boundary

This repository contains research code, benchmarks, specifications, simulations, papers, and experimental material. A research artifact is not automatically a commercial production component merely because it is present here.

Likewise, publication or discussion of a research concept does not by itself transfer ownership or grant commercial production rights to the underlying implementation.

## Important distinction

The license scope and the scientific evidence are separate questions.

The research program must continue to distinguish:

`implemented -> measured -> reproduced -> validated`

from:

`owned/licensed -> commercially deployable`

Technical claims about token reduction, compute conservation, energy reduction, latency, or economic savings require reproducible experiments regardless of licensing status.
