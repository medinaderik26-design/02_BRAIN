## Interpretation rule

Do not claim that Glyphin is novel merely because it uses structured memory. The current research direction already contains structured, graph, temporal, hierarchical, and compressed memory systems.

The potentially distinctive combination to test is:

**named symbolic states + lineage + measurable cohesion/resonance + recurrence/reinforcement + decay + canonical serialization + structural compression + exact reconstruction + deterministic downstream query verification.**

Actual improvement to LLM memory remains an open empirical question.
