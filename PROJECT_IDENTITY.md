# Glyphin Project Identity

This file establishes the canonical naming and ownership context for the Glyphin research project.

## Company

**Weisone Systems**

## Core technology

**Weisone Kernel**

The Weisone Kernel is the core kernel around which Weisone Systems is organized. Glyphin is the symbolic memory architecture/research system being developed in relation to the kernel.

## Research project

**Glyphin**

Glyphin must retain this exact spelling in research records, code documentation, experiment reports, manuscripts, and publication materials.

## Architecture relationship

```text
Weisone Systems
       |
       v
Weisone Kernel
       |
       +---- Glyphin symbolic memory architecture
       |
       +---- Local LLM integration
       |
       +---- Experimental / agent systems
```

## Naming policy

- Company: **Weisone Systems**
- Kernel: **Weisone Kernel**
- Memory architecture/research project: **Glyphin**
- Repository: `02_BRAIN`

The previous project documentation used an incorrect abbreviated spelling for the kernel. That terminology is superseded by **Weisone Kernel**. Historical records should not be rewritten solely to erase the old terminology; instead, current documents should use the canonical name and historical references may be preserved where they are part of the research record.

## Scientific boundary

Weisone Kernel is the systems/integration layer. Glyphin research claims must remain separately identified from Weisone Kernel integration claims. A successful kernel integration does not by itself validate the Glyphin hypothesis, and Glyphin benchmark results do not by themselves validate the entire Weisone Kernel system.
